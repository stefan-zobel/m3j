# Rosetta Code

Solutions in Modula-3 of tasks of [Rosetta Code](https://rosettacode.org),
taken from the RosettaCodeData repository
(https://github.com/acmeism/RosettaCodeData) by `tools/rosetta_prep.py`,
for the differential tests (`tools/diff_test.py`, `tests/diff/rosetta.list`).

- `orig/NAME.mod3` is a solution exactly as on Rosetta Code.
- `NAME/src` holds its units as a cm3 package; the first line of each unit
  names the task, its page and the license.
- `index.tsv` lists every solution and what happened to it.

The content of Rosetta Code, and so the solutions here (in `orig` and in the
units of each package), is available under the GNU Free Documentation
License 1.3, in
[`licenses/GFDL-1.3`](../../licenses/GFDL-1.3). The authors of a solution are
named in the history of its page on Rosetta Code.
